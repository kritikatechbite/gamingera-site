# Gamingera static website

## Pages
Five primary navigation pages: `index.html`, `games.html`, `guides.html`, `news.html`, `about.html`.
Five additional footer pages: `contact.html`, `privacy.html`, `terms.html`, `disclaimer.html`, `cookies.html`.

## Deploy to Netlify
Upload the ZIP contents or connect the site folder to Netlify. The site works with a free `.netlify.app` subdomain and does not require a build command.

## Customize
- Edit each HTML file for text and links.
- Edit `assets/css/style.css` for the theme and layout.
- Edit `assets/js/main.js` for mobile navigation and category filters.
- Replace local SVG assets in `assets/images/` if desired.
- The fonts are fetched from Google Fonts; fallback fonts are provided. All illustrations are stored locally.
- `contact.html` currently uses `mailto:` with `hello@gamingera.example`, which is intentionally a nonfunctional sample address. Replace this and add an actual form backend before launch.
- Privacy/terms/cookie/disclaimer pages are starter text. Review and adapt them to real website practices before publishing.

No visitor filtering, crawler blocking, hidden redirects or ad review cloaking is included.
